# ⚽ Sistema de Torneos de Futsal (WebApp con Supabase)

Esta aplicación permite gestionar torneos de futsal de forma dinámica, con fase de grupos, clasificación automática y rondas eliminatorias (semifinales y final).  
Todo está desarrollado en **HTML + CSS + JavaScript** y usa **Supabase** como base de datos.

---

## 🚀 Funcionalidades principales

✅ Gestión de equipos (agregar, editar y eliminar).  
✅ Configuración del torneo (días de juego, cantidad de partidos por día, hora de inicio).  
✅ Generación automática del calendario de partidos (round-robin, todos contra todos).  
✅ Registro de resultados por partido con goles de cada equipo.  
✅ Clasificación dinámica (PJ, PG, PE, PP, GF, GC, Pts, diferencia de goles).  
✅ Avance automático a eliminatorias (semifinales y final).  
✅ Diseño moderno y responsive.
